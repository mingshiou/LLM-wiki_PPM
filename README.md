# Plant Pathology & MPMI Knowledge Wiki

A persistent, compounding personal knowledge base for **Plant Pathology** and **Molecular Plant-Microbe Interactions (MPMI)**, built using the [Karpathy LLM Wiki pattern](https://gist.github.com/karpathy).

Maintained primarily by LLM agents with human-in-the-loop curation, structured for [Obsidian](https://obsidian.md/), and version-controlled via Git.

---

## 🗂 Structure

- **`AGENTS.md`**: Schema, operational rules, and workflows for LLM agents.
- **`raw/`**: Curated immutable source documents (papers, manuals, image assets).
- **`wiki/`**: LLM-generated and maintained Markdown knowledge base.
  - `pathogens/`: Fungi, oomycetes, bacteria, viruses, nematodes.
  - `diseases/`: Comprehensive disease profiles and epidemiology.
  - `hosts/`: Host plants, crops, and resistance genetics.
  - `molecular-biology/`: Effectors, NLR/PRR immune receptors, defense pathways.
  - `methods/`: Protocols, inoculation assays, and diagnostics.
  - `management/`: Chemical modes of action (FRAC), biocontrol, IPM.
  - `concepts/`: Foundational models and plant pathology principles.
  - `presentations/`: Thematic educational slides (Marp format).
  - `syntheses/`: High-level reviews and cross-topic comparative analyses.
  - `index.md`: Global catalog and link index.
  - `log.md`: Chronological operational log.

---

## 🚀 Workflows

1. **Interactive Ingest**: Raw papers are digested, discussed, and mapped into entity networks.
2. **Thematic Slides**: Generate educational presentation slide decks using [Marp](https://marp.app/) directly from compiled wiki concepts.
3. **Continuous Maintenance**: Periodic health checks for orphan pages, contradictions, and taxonomic revisions.
